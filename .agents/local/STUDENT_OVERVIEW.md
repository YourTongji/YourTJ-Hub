# YourTJ-Hub 项目简介（学生版）

> 适合具有一定软件开发基础的同学阅读
> 最后更新：2026-09-02

## 🎯 这是什么项目？

**YourTJ Hub** 是一个为同济大学校园打造的社区论坛平台。简单来说，它就像是一个"同济版贴吧 + 选课系统 + 评价平台"的组合体。

### 核心目标
- 让校园经验、问题和观点长期保存（不像短视频那样转瞬即逝）
- 一站式服务：论坛 + 课程评价 + Wiki 知识库
- 一个账号走遍所有服务（统一身份认证）

## 🏗️ 技术架构（简化版）

### 整体结构：一个"大背包"式应用

想象一个背包，里面装着所有需要的东西：
- **后端**（背包的骨架）：Go 语言编写，负责处理业务逻辑
- **前端**（背包的外观）：Vue 3 框架，负责网页界面
- **移动端**（背包的小口袋）：Flutter 框架，用于手机 App

关键特点：**所有东西打包成一个文件**！
- 传统做法：前后端分离，需要多个服务器
- 我们的做法：把前端"嵌入"到后端程序里，一个文件搞定

```
用户浏览器/手机 App
    ↓
单一可执行文件（内含前端 + 后端）
    ↓
数据库（PostgreSQL 或 SQLite）
    ↓
搜索引擎（Meilisearch，可选）
```

### 技术栈一览

| 类别 | 使用技术 | 类比 |
|------|---------|------|
| **后端语言** | Go 1.26 | 高性能、简洁，类似 Java 但更快 |
| **Web 框架** | Gin + Vue 3 | Gin 类似 Express.js，Vue 类似 React |
| **数据库** | PostgreSQL / SQLite | PostgreSQL 是专业数据库，SQLite 是轻量级本地数据库 |
| **搜索引擎** | Meilisearch | 专门的搜索工具，支持中文拼音搜索 |
| **移动端** | Flutter | Google 出品，一套代码生成 iOS 和 Android |
| **身份认证** | OAuth + OIDC | 类似微信登录、QQ 登录的标准协议 |


## 🛠️ 开发流程（简化）

### 分支管理
```
main (生产环境)
  ↑
  PR (合并请求)
  ↑
dev (开发主线) ← feat/* / fix/* / docs/* (功能分支)
```

### 开发步骤
1. 从 `dev` 创建功能分支（如 `feat/new-feature`）
2. 编写代码 + 测试
3. 更新文档
4. 提交 Pull Request
5. 代码审查通过后合并到 `dev`
6. 定期从 `dev` 合并到 `main` 发布

### 测试要求
```bash
# 后端测试
go test ./...

# 前端测试
pnpm test

# 构建测试
make build
```

## 💡 技术亮点

1. **单文件部署**
   - 传统：前端 + 后端 + Nginx 配置
   - 我们：一个可执行文件，简单高效

2. **数据库是真相源**
   - 搜索索引、缓存都可以重建
   - 数据库才是真正的数据源

3. **统一身份**
   - 论坛账号 = 身份源
   - 未来所有校园服务共用一个账号

4. **AI 友好**
   - 支持 AI 读取公开内容（`/llms.txt`）
   - 内置 AI 课程总结功能
