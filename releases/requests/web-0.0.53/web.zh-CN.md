# YourTJ Web 0.0.53

## 新增与改进

- 贴纸支持重命名和别名，增加贴纸市场、官方贴纸包和订阅管理；改善行内贴纸、列表预览和窄屏选择器的展示。
- 私信增加新会话接收权限；Web 与 App 共用未读数字或圆点偏好，关注按钮可区分“已关注”和“已互关”。
- 注册前说明邮箱与用户名规则，展示邮箱激活目标和重发状态；激活链接失效或会话异常时提供恢复入口，保留写作内容。
- 改善首页返回时的已加载列表和滚动位置恢复，减少实时更新造成的位置跳动；首次进入页面时预加载所需模块。
- 调整公告卡片折叠与排序、资料装饰展示、后台窄屏控件和中文字体，修复课程与排课筛选项被裁切的问题。

## 修复与安全

- 修复邮箱大小写、粘贴输入、验证码刷新、注册后会话和过期邮件重试问题；站点关闭验证码后，相关表单不再要求填写。
- 修复快捷发布恢复稿遗漏刚输入内容或恢复已清空内容的问题，改善窄屏编辑工具栏和键盘上方的链接表单。
- 图片类型按文件内容识别，修复摘要、图集可见性和链接预览；未被内容引用的上传仅上传者可读，满 7 天后回收。
- 内容审核拒绝必须说明原因；加强通知回调目标校验，限制后台统计查询，并更新相关安全依赖。

本次发布网站与服务端。Android、TestFlight 和 App Store 使用独立的移动端正式发布流程。
