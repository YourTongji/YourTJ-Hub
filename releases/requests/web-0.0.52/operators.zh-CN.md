## 部署与迁移

- 论坛使用 Go 1.26.10、Alpine 3.24；显式 Node 构建入口固定为 24.22.1。
- 更新 Markdown、Vue、Vite、AJV 及受控传递依赖；node-forge 尚无已发布修复，当前唯一用途为 RSA-OAEP 加密，不涉及该告警的 PKCS#1 v1.5 验签。若增加验签用途必须重新评估，继续保留 #1336 跟踪。
- Meilisearch 目标为 1.47.1。已有 1.11 数据必须先暂停索引写入，使用旧引擎生成 dump，导入独立新空卷并核对文档、设置、权限和搜索结果；禁止让新引擎直接打开旧卷。
- 将服务器 .env 的 MEILI_DATA_VOLUME 设为已验证新卷的实际名称，防止后续发布覆盖 compose 后重连旧卷；未设置时继续使用原 Compose 项目默认卷。切换前保留旧镜像与旧卷，恢复写入后核对搜索投影。
- 无 HTTP/OpenAPI 或数据库模型变更，本次仅发布 Web，不要求 Android/iOS 配套发版。
- 宿主机、内核和 1Panel 代理不随论坛镜像升级，须单独执行其安全维护与业务验收；本版本不宣称所有第三方告警或未知漏洞清零。
