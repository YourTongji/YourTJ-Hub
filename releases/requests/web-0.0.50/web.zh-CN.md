图片上传提示更精确：空文件、HEIC/HEIF/AVIF/TIFF 等暂不支持的格式、内容与扩展名不符或损坏，会分别收到对应提示；头像、帖子配图与直传上传均适用。

新增管理员可配置的 AI 图文审查，默认关闭；开启后的默认「仅记录」模式不影响发布。管理员选择「发布前检查」后，被拦截的内容会保留在编辑器中，并显示「内容暂未发布」及修改建议；转入审核的内容和配图仅作者与有权限的审核人员可见。选择「发布后检查」时，内容先保存为待审核，后台检查放行后才公开；判定需要人工确认或检查失败时，继续留在审核队列。

作者可查看自己「审核中」的话题和回复。人工审核通过或拒绝后会发送站内通知，并按推送设置发送浏览器通知；通过通知可跳转查看内容。后台自动检查放行不另发通知。

版主工作台新增「待审核」页签：版主可在前台直接审核管辖分类内的待审话题与回复，条目附 AI 触发原因与图片预览；管理后台审核队列同样展示这些信息。

课程评价：同一条评价的「有用」与「不喜欢」现在互斥，切换后计数立即更新。

徽章图标视觉统一：系统徽章图形按统一光学尺寸缩放，在头像角标内大小一致；图形更新后自动加载新版本。

移动端网页新增手势：右滑打开菜单、左滑关闭抽屉，首次使用会有一次性滑动提示；校园地图、图片轮播等横向滑动区域不受误触影响。

信息流：无标题瞬间的未读圆点改为显示在摘要旁，不再渲染空标题行。

发布触发验证码时新增说明文字，解释该要求何时自动解除；第三方账号注册引导页新增「使用其他方式登录」入口，并保留原有跳转。

安全与隐私修复：两步验证状态读取失败时，登录与验证码校验直接拒绝而不再放行；应用日志对授权回调、登录跳转和来源网址中的敏感参数进行脱敏。
