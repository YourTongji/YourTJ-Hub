# YourTJ Web 0.0.51

## 新增

- 支持持久匿名身份、匿名主页与内容可见性设置；个人主页分区隐私由服务端统一校验。
- 发帖和改稿采用异步审核，改稿审核期间保留已公开版本；作者可查看拒绝原因、修改重提，并对被拒版本提出申诉。
- 个人贴纸上传先审后用；管理员可管理和上传头像框等资料装饰资源。
- 作者可以禁止机器人回复；Agent 增加持久互动事件、可靠 Webhook、幂等回复及主题图集读取能力。
- 增加跨平台通行密钥支持；部署启用并完成域名关联验证后可使用，原有登录方式保留。
- 增加 B 站、Apple Music 链接预览，以及管理端可配置的外链免确认白名单。
- 管理后台增加内容贡献汇总、趋势与用户排行；草稿箱支持删除草稿。

## 改进与修复

- 调整推荐信息流的排序与质量观测，改善返回位置恢复和刷新时已见内容过滤；信息流排除双向屏蔽用户的内容。
- 统一通知分类与私信推送，隔离推送投递失败，修复分类切换、节流及审核通知相关问题。
- 改善课程、排课和 Wiki 的按需加载及缓存，修复排课弹窗首次打开、课程地点展示和 Wiki 落地滚动问题。
- 统一 Emoji 的 Twemoji 展示，修复其在文本、代码和图片预览中的样式干扰。
- 修复图片 EXIF 方向、主题操作同步、公告轮播高度、非安全上下文 UUID 生成及注册用户名失败提示。

本次为网站与服务端发布，不包含 Android 或 iOS 正式安装包的公开发布。
