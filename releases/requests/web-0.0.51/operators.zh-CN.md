# Web 0.0.51 运维说明

## 发布身份与部署

- 固定源码为 `f34e7b04c2880b4ab1eb3ee220291715ba2ec72f`，上一成功 Web 基线为 `v0.0.50`。由受控 Web publisher 构建单二进制、归档并生成镜像，生产按镜像 digest 部署，等待健康检查并核对运行二进制。
- 本请求仅发布 Web。Android、TestFlight 与 App Store 必须使用各自完成验收和审核的正式请求；预发成功不代表正式上架。

## 数据库与后台任务

- 发布前确认生产数据库备份可恢复并预留迁移时间。启动会更新 schema，涉及匿名身份、推荐信息流、Agent 事件/Webhook、通行密钥、资料装饰与审核申诉等表，以及主题 Agent 回复策略和帖子事件深度字段。存量大表补列可能增加锁等待，部署期间观察迁移耗时和健康状态。
- 应用数据迁移目标版本为 33：旧 pending 内容纳入版本和审核队列、回填 Bot 徽章，并为旧被拒内容建立可申诉版本。失败不推进版本，可按原流程重启重试；不要手工跳过迁移版本。
- 检查 `content-review`、`content-published` 和 Webhook 队列是否推进，以及失败重试和人工审核积压。模型故障会转人工审核，不视为自动通过。

## 配置与兼容性

- 使用本源码的部署模板和实例声明渲染配置，不直接覆盖生产凭据。通行密钥默认关闭，启用前按部署文档验证 RP ID、允许来源及 iOS/Android 域名关联；不能把代码部署等同于设备登录验收。
- AI 审核配置默认仅记录；启用异步审核前校准规则并确认所用 provider 的隐私设置。待审正文和图片会发送给配置的模型服务，禁止将正文、密钥或原始推理证据写入交付记录。
- 检查推荐信息流和观测开关、通知/Webhook 配置、外链白名单及图片上传模式。对象存储直传受网络或 CORS 限制时，可使用已有的强制服务端代理上传开关；不因此放宽存储权限。
- 发布后检查生产首页、OIDC discovery、登录与退出、发帖/改稿/申诉、上传、通知、搜索及排课，并复查旧客户端兼容性。预发或 dev 的结果不代替生产冒烟。

## 故障与回滚

- 任一必要发布步骤失败仍按失败处理；使用原候选及原始产物恢复，不复用已消耗的移动构建号，不覆盖不可变归档。
- 镜像或配置回滚不会回滚数据库。回退前先确认旧版本与已升级 schema 的兼容性；不得自动恢复或覆盖生产数据库，迁移不兼容时优先向前修复。
