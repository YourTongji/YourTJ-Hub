## 页面与数据范围

**Current**：`apps/status` 提供无需登录的独立状态页面，目标域名 `status.yourtj.de`。
Vue 静态产物、Netlify Functions 与 Blobs 构成独立部署，论坛侧栏只保留「运行状态」外链。
页面不依赖论坛 API、Cookie、字体服务器或论坛静态资产。字体、色彩、面板和间距沿用
YourTJ 视觉语言，支持明暗主题、手机布局与中文／英文／日文／德文。

- **服务可用性**：独立 Uptime Kuma 已发布状态页的监控项、最新检查／响应时间、
  来源计算的近 24 小时可用率与最近最多 100 次真实检测。可用率基于已采集数据，可能
  不足 24 小时；检测条不是每日可用率，不补绿色。悬停及键盘聚焦的详情原位过渡，
  连续扫过条间空隙不闪烁、不改变面板高度；支持 Escape 和减少动态效果设置。
- **服务器**：仅展示配置的一个 Komari 节点，包括当前 CPU、内存、磁盘、网络速率、
  主机运行时长和 CPU／内存曲线。资源历史独立切换 `1h/6h/24h/7d`，默认 `1h`，
  当前资源卡始终使用最新采样。历史缺失不补零；最多 120 点并保留整个范围，明显
  采样间断会断开曲线；跨日范围的时间轴同时显示日期和时间。历史内存容量缺失时，
  使用当前主机容量折算，并在页面披露。
- **访问统计**：Umami 公开共享页的独立访客、浏览量、访问次数、跳出率、平均访问
  时长和采集时最近五分钟的独立访客，支持滚动 `24h/7d/30d`。在线人数是采集快照，
  不宣称浏览器访问时的实时人数。趋势按 UTC 小时／天分桶，显示使用浏览器时区；
  分桶独立访客不能相加当作全范围独立访客。跳出率按跳出访问／访问次数计算，
  平均时长按访问总秒数／访问次数计算；无访问时为缺失值。

容量使用 MiB/GiB，网速使用字节每秒。缺失值显示 `—`，真实零值显示 `0`。
UI 脚本必须启用才能读取指标；无脚本入口提供独立 Uptime 页面链接。

## 状态与新鲜度

页首优先使用独立 Uptime 检测，保留可访问、异常、部分异常、维护、待确认与未知。
来源过期／不可用、没有最新检测、检测超过五分钟时都不能显示正常。未配置 Uptime
时才退回探针上报信号；高 CPU 或主机运行时长不代表网站可用率。

**Current**：当前资源与 Uptime 每分钟采集；资源历史及访问统计每五分钟采集。
浏览器每 30 秒读取同源 `/api/status`，隐藏页面时暂停。范围切换取消旧请求并忽略乱序
响应，切换资源曲线时不把旧范围曲线标成新范围。公开 API 只读快照，访客请求与取消
不会触发上游采集；最多十五秒的 Netlify CDN 缓存降低读取次数。

当前资源与可用性来源获取时间超过 150 秒为过期；历史与流量超过十分钟为过期。
主机最新采样也须在 150 秒内；所有获取／采样／检测时间最多容忍一分钟未来偏差，
无效时间不作为健康信号。资源历史有独立获取时间和过期提示，不能随当前资源刷新
冒充新历史。浏览器即使反复读到缓存也会按原始时间重新判断状态。

上游采集失败保留上次成功数据及其时间戳，立即标为过期。成功数据最长展示十五分钟；
超时返回不可用及空数据。读取 Blobs 失败返回 503，页面保留已经显示的数据并取消
正常状态。来源配置变更切换缓存身份，停用来源不会继续读取其旧快照。

## 隐私与故障边界

只采集公开 Umami 共享统计、公开 Komari 指定节点和已发布 Uptime 监控项，输出固定
白名单字段。浏览器无法指定上游 URL、节点或监控项；共享 token 仅用于采集请求，
不持久化、不返回浏览器，不需要管理员账号。服务器 IP、账单、备注、访客会话、
访问路径、检测目标 URL、上游错误文本和自定义 CSS 都不在公开响应中。

状态站的页面、采集和快照读取都独立于论坛；Uptime Kuma 已独立部署。监控站或 Netlify
自身发生故障时，页面依数据年龄显示未知／过期，不能把缺少数据判为网站正常。

**Partial**：独立应用、API 契约、测试和部署配置已具备；Netlify 项目、正式 DNS 与云端
定时采集仍需要运营配置并验收。Flutter 原生页面没有实现。

**Planned**：事故公告管理、长期每日可用率历史与通知订阅。

## 配置与契约

按[Netlify 部署手册](../operations/status-netlify.md)设置项目、环境变量与域名。
独立 API 以 [`apps/status/api/openapi.yaml`](../../apps/status/api/openapi.yaml) 为准，
生成 TypeScript 与验证在同一应用维护。论坛 Gin API 和移动客户端不包含状态数据镜像。
