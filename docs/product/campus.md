## Supported experience

Web/API/schema: `Current`. `/campus` 是登录用户自己的校园工作台。未登录用户可查看功能说明；连接操作要求有效的 YourTJ 人类用户会话。入口位于侧栏和设置的账号绑定区。校园身份同时支持 Web/Flutter 登录和注册；不在公开用户资料显示真实姓名或学号。

校园页复用论坛的 PageHeader、SectionHeader、EmptyState 和通用卡片、按钮、标签、输入框样式。学业图表使用论坛主题主色；官方课表与排课器共用 ScheduleTimeGrid 展示组件、节次网格、跨节合并布局、课程卡片和配色，并读取相同的公开节次作息配置。校园课表为只读展示，不初始化排课器状态或写入 localStorage；浅色、深色主题与移动端布局跟随论坛，不维护独立配色。 Web 校园页、导航与账号设置入口、消息弹窗和管理员调休面板支持中文、英语、日语、德语。日期、问候与随机短句随界面语言更新，教学周和当天课程始终按上海时区计算；固定指标名、表头与单位翻译显示，学校返回的姓名、课程名、通知正文和管理员输入的规则名称保留原文。

`Current`：登录和注册页在配置有效时展示“同济统一认证登录”。用户在学校完成认证后，已有绑定进入原账号；从未绑定过的身份进入独立注册页填写用户名和密码，提交后才原子创建普通账号、自动设置“学号@tongji.edu.cn”并激活，同时建立校园连接，无需邮件激活。仅接受经官方接口验证的数字学号，公开用户名和昵称使用用户填写的用户名。注册开关、域名白名单、每日限额照常生效；冻结、机器人和已注销账号不可登录。同一邮箱已被使用或在换绑确认期时不自动合并，提示先登录已有账号再绑定。学校认证已提供可信身份，不需要再次邮件验证；注册完成前不创建账号、不签发论坛会话。按钮说明自动注册与连接的效果，并提供已发布服务条款和隐私政策链接。

曾绑定身份解绑、换绑或注销后不能再自动注册；需先登录或找回已有账号，再显式绑定，仍可转绑到其他已有账号。服务端长期保留仅含 HMAC 身份指纹的防重复注册记录，不保留用户关联、原始学号或令牌，邮箱变更和服务重启不重置记录。每日注册限额与密码注册共享事务锁，已注销账号仍计入创建当天的名额。

学校登录不覆盖已有账号的邮箱、激活状态或密码；已有绑定不受关闭新注册影响。解绑及换绑同时改变后续学校登录所对应的关系，普通论坛会话与邮箱生命周期保持原规则。学校登录重新授权会刷新校园凭据并保持当前身份的绑定时间，无需重复校园确认；从校园页发起的绑定、换绑、更新授权仍需确认。

一个 YourTJ 账号只能绑定一个同济官方身份，一个官方身份也只能绑定一个 YourTJ 账号。身份以学校 `student_info.userId` 经服务端 HMAC 后确定，学校签名 ID token 与 userinfo 的 subject 必须匹配；返回学号时再核对两接口的一致性。数据库主键和唯一索引同时约束两个方向。

用户在学校页面认证后，回到校园页核对脱敏身份并确认绑定。换绑先验证新身份，再使用连接版本进行原子替换；身份占用或版本冲突保留旧绑定。换绑成功后绑定时间更新为当前身份的绑定时间，同身份重新授权保留原绑定时间。重新授权强制显示学校登录页，只接受当前已绑定身份，学校回调后需确认才替换本站保存的凭据。消息详情弹窗识别待确认的授权并直接提供确认入口，确认后重新读取列表并重试当前消息，不重复发起学校登录。Web 跨学校登录返回仅在 sessionStorage 暂存当前论坛用户、绑定版本、消息 ID 和原标签，最多十分钟且读取即删除；确认后依据新列表校验归属，不持久化消息标题或正文。解绑需要确认，删除本站校园凭据、释放唯一占用并清除未完成的授权；远端令牌撤销尽力执行，失败不阻断本地解绑。注销论坛账号也删除校园绑定，并在可解密时尽力撤销学校 refresh token；远端不可用不阻断本地删除。

## School data

- `Current`：当前校历、按周个人课表、本科历年成绩与学期绩点、综合 GPA/均分/学分、四六级成绩、历年校历、学校消息列表和消息正文。首页按学校时区显示教学周、星期与时段问候，仅在私密页面读取本人姓名；随机祝福或冷笑话来自内置文案，可点击换一句。首页依次显示最近五条消息和今日课表，GPA、均分、学分仅在学业记录中展示，成绩数据按进入页面时加载。字段只取学校实际返回值，缺失值显示为空，不转换为零。
- `Partial`：体测数据、体测健康和调课安排的 scope 已识别，但当前应用实测未返回可用记录；连接状态页显示上游不可用，数据可视化尚未实现。考试安排未被当前应用授权，不发起该请求。
- `Current`：课表周次切换、成绩/消息搜索、学期平均绩点条形图、学分进度和四六级成绩对比。个人学校课表与 `/schedule` 的用户选课方案分开保存；读取官方课表不覆盖排课草稿。
- `Current`：Web 与 Flutter 的“我的课表”提供“导出课程日历”，导出当前学期全部有明确时间的课程为 `.ics`，不受当前选中周次限制。网页下载文件；App 调起系统分享，可保存文件或交给支持导入的日历应用，iPad 提供分享锚点。服务端共用一份生成逻辑，按学校返回的教学周逐次展开，使用校园课表相同的节次作息；上海时间转换为明确的 UTC 时间，包含课程名、教师、教室及校区，不包含姓名、学号或授权凭据。重复源记录合并；同一账号未变动的课程安排使用稳定的事件 UID，但重复导入的去重行为取决于目标日历应用。
- `Current`：日历导出是手动快照，不是订阅。按管理员确认的规则调整放假与补课，不推测其他调课；课表变化后需重新导出，建议使用独立课程日历并替换旧内容。校历必须提供有效的周一学期起始日、结束日期和周数；课程必须提供明确周次、星期与节次，信息不完整时拒绝导出并提示重试，空课表提示无可导出课程。
- `Current`：App 使用 Flutter 原生校园首页、按周课表、学业记录与图表、消息列表及纯文本正文、校历和连接管理；共享 Gf 主题与排课器网格组件，支持中英日德四种界面语言、大字体及窄屏。底栏“校园”打开原生校园页，首页顶部直接展示课程评价、排课器和 Wiki 快捷入口；未登录、未绑定或学校数据读取失败时也可进入公共工具。入口复用“探索校园”和搜索的组件，推入原生页面，返回后仍位于校园分支；“探索校园”继续提供课程推荐。学校认证仅使用受限 WebView 交接当前论坛会话，允许官方 HTTPS 域名，回调后返回原生确认界面。
- `Current`：Android 与 iOS 提供校园课表桌面小组件，分别使用 Jetpack Glance 与 WidgetKit/SwiftUI。小组件只读主 App 最后一次完整校园快照派生的最小本地投影，永不联网；schema 2 保留服务端解析的今天，并携带八天滚动窗口供上海午夜后离线切日。Android 小尺寸显示当前/下一节，中尺寸显示今天，大尺寸以“今天｜明天”双栏展示；另提供默认 4x3 的“课程时间线”，顶部显示日期、周次和星期，箭头可在今天与明天间切换，课程列表可纵向手势滚动且不显示滚动条，课程项显示起止节次和时间、课程名、教室与教师姓名（不含工号）。iOS 小尺寸显示当前/下一节附近的两门完整课程及一门名称和开始时间缩略条目（当天不足三门时按实际数量）；中尺寸将小型日期标题置于顶栏，当天不超过两门课程时左右展示今天与明天，否则按时间顺序把当天课程接续排在两栏；大尺寸展示今天与明天。课程不足时不填造条目，空间不足时按完整课程项计数收尾。iOS 课程条目展示名称、教室、教师、起止时间，省略校区并将“教学北楼”等教室名称缩为“北”等；左侧竖色条沿用 Web 课表色阶。每天的标题展示周次、星期和简写日期，右上角保留标识，底部展示含日期与时间的最后更新时间。iOS 小尺寸不显示进度横条。Android 提供 2x1、4x2 及可扩展 4x4，iOS 提供 systemSmall、systemMedium、systemLarge。桌面数据不读取或修改 `/schedule` 排课方案。
- `Partial`：移动端学校官方登录的真机端到端验证未完成；原生页面由组件测试、模拟数据集成流程覆盖。

## Holiday adjustments

Web admin/API/Web and Flutter export: `Current`。站点管理权限用户可在 `/admin/settings/campus-calendar` 输入学校通知及明确年份，使用已有 AI 课程总结的模型配置生成草稿。AI 只接收通知和年份，不接收个人课表或校园凭据。草稿以放假日期区间和“原教学日 → 实际上课日”展示，附星期和待核实事项；支持逐项编辑、添加、删除，再点击“应用规则”发布。AI 解析只追加到编辑草稿，不修改已发布规则；保存失败保留草稿，并发修改以内容版本拒绝覆盖。没有 AI 配置时仍可手动编辑。

`Current`：假期首尾日均停课。补课搬用原教学日所在周的课程，包括单双周约束，替换目标日原有课程，同时移除原日安排；不会递归套用其他补课规则。例如 2026-09-20 安排 2026-10-06 教学工作，使用 10 月 6 日所在教学周的周二课程。重叠假期、重复源/目标、目标落在假期、循环/连锁或无效日期均拒绝发布。跨年使用完整日期，规则不会自动延续至下一年。

`Current`：Web 与 Flutter 导出按钮附近的“开启调休规则”默认打开；可查看当前已发布规则，关闭后导出原始课表。导出使用请求时读取的最新规则；没有规则时与原课表一致。规则读取失败时不静默忽略，用户可重试或主动关闭调休。今日课表始终应用管理员发布的调休规则，不受导出开关影响；Web 和 Flutter 共用服务端按上海日期计算的结果。补课使用原教学日所属周次（含单双周）和星期，替换实际补课日原有课程；放假及已调走的日期不显示课程，并显示调休名称或原教学日说明。规则读取失败、校历缺失或补课源日期不在当前学期时提示错误，不回退为原始课表或误报无课。跨上海午夜使 App 内旧日结果失效；Widget 可从最近一次成功刷新生成的八天本地窗口切换教学日，未来日期为 `unknown` 时提示刷新，不后台联网。校内原始周课表保持学校数据。已导入文件不会自动更新，规则变更后需重新导出并替换旧日历内容。

## Credentials and lifecycle

学校密码只在学校官方页面输入。Go 服务端持有学校 access/refresh token，AES-256-GCM 加密落库并绑定论坛 user ID；加密密钥与身份 HMAC 密钥由运行环境 secrets 提供。校园数据接口只返回脱敏身份和明确字段白名单的数据投影，不返回 token、学号原文、准考证号或学校用户对象。学校新注册账号的推导邮箱作为普通私密邮箱存入 users，账号设置及正常邮箱登录/找回流程可读取和使用它，不进入公开资料。

access token 到期前按需刷新；学校返回 401 时最多再刷新一次。刷新无效保留身份占用，页面提示重新授权。短暂网络故障不解除身份。刷新具有进程内互斥及数据库租约，解绑/换绑使用版本条件，已过时的数据请求不能恢复连接或返回原身份数据。

消息正文权限不足时提供更新授权入口，原绑定保持不变。消息详情先核对消息属于当前用户的学校列表；正文转换为纯文本和明确的外部链接，不执行学校 HTML，也不自动加载正文图片。关闭弹窗或身份变化会清空正文并取消请求。

Web 校园数据仍只在请求与客户端内存中处理，不进入 localStorage、公开 SSR payload、搜索索引、论坛帖子或遥测。校园文档禁用 Umami 统计/回放和自定义脚本；进出校园页强制整页加载，以卸载原页面脚本。学校回调即使遇到会话失效、账号不可写、限流或配置关闭也跳转到无授权参数的校园 URL，不交换被拒绝请求中的授权码。所有校园 API 使用 `private, no-store`；Web 离页清理内存请求与数据。

`Current`：Flutter 在现有 Drift 设备库保存 `profile`、`calendar`、`timetable`、`today` 四项白名单的单文档快照，按规范化 API origin、论坛数字账号和校园绑定版本隔离。写入只发生在四项读取全部成功后并原子替换；普通网络失败保留最后成功快照，损坏或未知 schema 安全清除。成绩、考试、消息列表/正文、学校凭据、token、cookie、学号和邮箱不进入该快照。`profile` 仅供登录后的私密校园页离线恢复，其中可含学校返回姓名；桌面 Widget 的独立 Projection 再移除姓名及其他不需要字段。 每份 JSON 上限 1 MiB，设备最多保留 4 个 site/account scope，写入按提交时间淘汰最旧项；读取时删除超过 30 天、时间异常或损坏的快照，不后台联网续期。

Flutter 离开校园标签时仍销毁私密视图并取消请求，进入后台只清空五分钟前台内存层；设备快照继续留在 App 私有存储。启动校园页先恢复当前 site/account 的设备快照，再请求绑定状态核验；临时网络失败继续显示最后快照和错误，明确的会话/授权/身份错误才清除。刷新使用版本隔离，忽略过期响应；绑定成功后重新获取数据。校园绑定授权尝试绑定论坛会话 jti；学校登录使用独立登录用途 state 与 HttpOnly 浏览器证明，不要求已有论坛会话，也不会降级为账号绑定。state、nonce、PKCE verifier、待注册凭据与待确认 token 在进程内最多保留十分钟；重启会使未确认流程失效。该授权流程适用于单实例部署，多实例需要会话粘滞及共享授权事务存储。

`Current`：Flutter 今日页按日期与问候、今日课表、最近校园消息排序。基本资料、校历、课表和消息列表仍可在前台内存中保留最多五分钟，成绩、学业汇总、考试成绩、消息正文和凭据不进入内存缓存。下拉刷新保留同一身份的内容并显示进度；只有白名单四项全部成功才原子提交设备快照与 Widget Projection，任一区块失败显示错误并保留旧展示/快照。确认绑定等操作因 CSRF 或邮箱验证要求被拒绝时保留原身份与数据；会话失效、账号冻结或明确的校园身份失效错误才清除。退出登录、切换账号或站点、解绑、换绑和授权失效清除内存、设备快照与桌面 Projection；迟到响应不得重新写入。可见页分钟时钟不发起网络请求；上海日期变化只使旧教学日数据失效，等待用户手动刷新。 私密校园页显示设备快照提交时间、过期与连接核验失败提示；已恢复快照的四项白名单在切换页面时不因五分钟内存过期重取，缺失/跨日内容显示手动刷新入口。连续刷新合并为一批，身份变更仍中断旧刷新；普通区块错误保留同日可用内容，明确教学规则失效不展示旧课程。设置“清除校园缓存”删除校园内存、全部校园设备快照和桌面投影，不解绑学校、不删除创作草稿或排课方案；清理期间的旧请求不能回填，部分清理失败明确提示并可重试。参见[设备快照与桌面课表决策](../decisions/0035-campus-device-snapshot-and-schedule-widgets.md)。

生产到 dev 的数据库同步排除校园绑定表和身份保留表的数据；两环境独立密钥、独立绑定。关闭功能或更换密钥前按[运维说明](../operations/campus.md)处理存量凭据。

用户主动导出的日历文件是校园数据不落盘规则的显式例外。导出接口仍需本人会话，校历与课表共用授权刷新和绑定版本检查，响应 `private, no-store`，服务端不保存文件、不提供公开订阅链接。Web 在内存中创建下载对象并回收；Flutter 只在点击导出后创建临时文件，分享完成、取消或失败后删除自身临时文件，系统分享缓存由操作系统/插件管理。用户保存或交给日历应用的副本包含课程及地点，由用户和目标应用管理，解绑不会撤回已导出的副本。未完成的导出在离页、切换账号或刷新时取消，迟到响应不会触发下载或分享。
