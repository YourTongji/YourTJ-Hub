## Supported experience

Web/API/schema: `Current`. `/campus` 是登录用户自己的校园工作台。未登录用户可查看功能说明；连接操作要求有效的 YourTJ 人类用户会话。入口位于侧栏和设置的账号绑定区。校园身份不充当论坛登录方式，也不在公开用户资料显示真实姓名或学号。

校园页复用论坛的 PageHeader、SectionHeader、EmptyState 和通用卡片、按钮、标签、输入框样式。学业图表使用论坛主题主色；官方课表与排课器共用 ScheduleTimeGrid 展示组件、节次网格、跨节合并布局、课程卡片和配色，并读取相同的公开节次作息配置。校园课表为只读展示，不初始化排课器状态或写入 localStorage；浅色、深色主题与移动端布局跟随论坛，不维护独立配色。

一个 YourTJ 账号只能绑定一个同济官方身份，一个官方身份也只能绑定一个 YourTJ 账号。身份以学校 `student_info.userId` 经服务端 HMAC 后确定，学校签名 ID token 与 userinfo 的 subject 必须匹配；返回学号时再核对两接口的一致性。数据库主键和唯一索引同时约束两个方向。

用户在学校页面认证后，回到校园页核对脱敏身份并确认绑定。换绑先验证新身份，再使用连接版本进行原子替换；身份占用或版本冲突保留旧绑定。重新授权只接受当前已绑定身份，学校回调后需确认才替换本站保存的凭据。消息详情弹窗识别待确认的授权并直接提供确认入口，确认后重新读取列表并重试当前消息，不重复发起学校登录。解绑需要确认，删除本站校园凭据、释放唯一占用并清除未完成的授权；远端令牌撤销尽力执行，失败不阻断本地解绑。注销论坛账号也删除校园绑定。

## School data

- `Current`：当前校历、按周个人课表、本科历年成绩与学期绩点、综合 GPA/均分/学分、四六级成绩、历年校历、学校消息列表和消息正文。首页按学校时区显示教学周、星期与时段问候，仅在私密页面读取本人姓名；随机祝福或冷笑话来自内置文案，可点击换一句。首页依次显示最近五条消息和今日课表，GPA、均分、学分仅在学业记录中展示，成绩数据按进入页面时加载。字段只取学校实际返回值，缺失值显示为空，不转换为零。
- `Partial`：体测数据、体测健康和调课安排的 scope 已识别，但当前应用实测未返回可用记录；连接状态页显示上游不可用，数据可视化尚未实现。考试安排未被当前应用授权，不发起该请求。
- `Current`：课表周次切换、成绩/消息搜索、学期平均绩点条形图、学分进度和四六级成绩对比。个人学校课表与 `/schedule` 的用户选课方案分开保存；读取官方课表不覆盖排课草稿。
- `Current`：App 使用 Flutter 原生校园首页、按周课表、学业记录与图表、消息列表及纯文本正文、校历和连接管理；共享 Gf 主题与排课器网格组件，支持中英日德四种界面语言、大字体及窄屏。课程、排课和 Wiki 工具保留在独立的“探索校园”页。学校认证仅使用受限 WebView 交接当前论坛会话，允许官方 HTTPS 域名，回调后返回原生确认界面。
- `Partial`：移动端学校官方登录的真机端到端验证未完成；原生页面由组件测试、模拟数据集成流程覆盖。

## Credentials and lifecycle

学校密码只在学校官方页面输入。Go 服务端持有学校 access/refresh token，AES-256-GCM 加密落库并绑定论坛 user ID；加密密钥与身份 HMAC 密钥由运行环境 secrets 提供。前端只收到脱敏身份和明确字段白名单的数据投影，不收到 token、学号原文、准考证号或学校用户对象。

access token 到期前按需刷新；学校返回 401 时最多再刷新一次。刷新无效保留身份占用，页面提示重新授权。短暂网络故障不解除身份。刷新具有进程内互斥及数据库租约，解绑/换绑使用版本条件，已过时的数据请求不能恢复连接或返回原身份数据。

消息正文权限不足时提供更新授权入口，原绑定保持不变。消息详情先核对消息属于当前用户的学校列表；正文转换为纯文本和明确的外部链接，不执行学校 HTML，也不自动加载正文图片。关闭弹窗或身份变化会清空正文并取消请求。

校园数据只在请求与页面内存中处理，不保存课表/成绩快照，不进入 localStorage、公开 SSR payload、搜索索引、论坛帖子或遥测。校园文档禁用 Umami 统计/回放和自定义脚本；进出校园页强制整页加载，以卸载原页面脚本。所有校园 API 使用 `private, no-store`；离页清理内存请求与数据。Flutter 校园记录不进入离线库、设备偏好或状态恢复；切换账号、离开校园标签或进入后台时销毁私密视图并取消请求。刷新使用版本隔离，忽略过期响应；绑定成功后重新获取数据。授权尝试绑定论坛会话 jti，state、nonce、PKCE verifier 与待确认 token 在进程内最多保留十分钟；重启会使未确认流程失效。该授权流程适用于单实例部署，多实例需要会话粘滞及共享授权事务存储。

生产到 dev 的数据库同步排除校园绑定表的数据；两环境独立密钥、独立绑定。关闭功能或更换密钥前按[运维说明](../operations/campus.md)处理存量凭据。
